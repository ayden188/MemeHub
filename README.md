Orion MemeHub v4.0
Orion MemeHub est une plateforme web ultra-fluide dédiée à la découverte et au partage de mèmes. Propulsée par l'API Giphy, cette Web App se distingue par son moteur de rendu optimisé et son interface utilisateur moderne ("Glassmorphism").

✨ Fonctionnalités Clés
🔥 Flow Temps Réel : Affichage des tendances mondiales via l'API Giphy.

🚀 Focus Mode (Upload) : Une interface dédiée et immersive pour publier vos propres GIFs sans distractions.

🎰 Surprise Action : Un bouton "Random" avec une animation de dé à 720° pour découvrir du contenu insolite.

⭐ Système de Favoris & Likes : Sauvegarde persistante de vos mèmes préférés grâce au localStorage.

🏆 Mème du Jour : Un contenu exclusif sélectionné et mis à jour toutes les 24 heures.

📱 Web Share API : Partage natif sur mobile (WhatsApp, Twitter, etc.) en un clic.
